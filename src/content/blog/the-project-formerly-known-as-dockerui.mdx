(RIP Prince) If you’ve been following along on GitHub you may know that DockerUI is no longer DockerUI, it’s currently ‘<a href="https://github.com/kevana/not-dockers-ui" target="_blank" rel="noopener">not-dockers-ui</a>’ until I can come up with a better name, and I’ve taken over as the owner of the repo from Michael Crosby.

Why? Three weeks ago two security vulnerabilities were disclosed for the project (<a href="https://github.com/kevana/not-dockers-ui/releases/tag/v0.10.1" target="_blank" rel="noopener">that are now fixed</a>) and it became clear that some people thought this was an official Docker project. To clear up the confusion and comply with Docker’s official brand guidelines I will rename the project. You can join the discussion <a href="https://github.com/kevana/not-dockers-ui/issues/197" target="_blank" rel="noopener">here</a>.

It’s not going away, I’m not going away. Once we pick a name I’ll get automated builds set up on the hub again.
